# Production roadmap

- Select an institution-approved identity integration and prefer managed EAP-TLS certificates.
- Add redundant FreeRADIUS instances, PostgreSQL, backups, retention controls, and audit policy.
- Configure approved Cisco/controller RADIUS clients, VLAN/role policy, DHCP/DNS, routing, and firewalling.
- Add monitoring, alerting, load testing, security review, disaster recovery, and a controlled library pilot.
- Obtain IT approval and communicate privacy, support, and rollout policies to students.

All topology, IP ranges, VLAN IDs, controller models, Google Workspace licensing, and security policies are discovery requirements; none are assumed here.
